# Finanza

**Tu negocio, bajo control.**

Aplicación financiera y tributaria para negocios independientes en Perú.

## Tecnologías utilizadas

- Next.js
- React
- TypeScript
- Supabase
- Tailwind CSS

## Cómo ejecutar el proyecto

Primero, instala las dependencias:

```bash
npm install
```

Después, inicia el servidor de desarrollo:

```bash
npm run dev
```

Abre http://localhost:3000 en tu navegador.

## Estado del proyecto

Finanza se encuentra en desarrollo. Su objetivo es ayudar a los negocios independientes a gestionar sus ingresos, gastos y obligaciones tributarias.
